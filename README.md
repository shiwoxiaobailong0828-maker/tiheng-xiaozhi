# 体衡小智 · 运动健康与体能实验室

给大学生用的运动健康自测与训练入门网页应用：身体档案建一次，代谢、心率、体能、训练负荷全部公式现算。单文件 `index.html`，离线可用，零外链。

## 功能（10 个页签）

- **首页**：今日速览（档案摘要、心率五区色带、本周负荷）
- **身体档案**：BMI 与中国成人分级、体脂率估算（Deurenberg）；6 个预设学生样本一键载入
- **能量代谢**：BMR（Mifflin-St Jeor）、TDEE 四档活动系数、运动补水估算
- **心率实验室**：最大心率与心率储备、Karvonen 五区
- **体能评估**：Cooper 12 分钟跑 VO2max、Epley 1RM、肺活量体重指数、跑步热量与配速
- **训练规划**：sRPE 训练负荷与周分档、三套目标周计划模板
- **运动模拟**：一周训练填表，先模拟整周负荷再执行
- **知识卡**：60 张（6 类 × 10）
- **知识测验**：50 题（单选 35 + 判断 15）
- **健康手记**：训练记录与周汇总，本地保存，可导出报告

## 口径

全部数值为**教学估算**（公开公式计算），不是医疗诊断，也不是官方体测评分。静息心率偏高或运动不适时，应用会提示先咨询校医院或医生、从低强度开始。数据只存浏览器本地（localStorage），不上传。

## 本地打开

下载 `index.html` 后用浏览器直接打开即可，无需服务器、无需联网。
